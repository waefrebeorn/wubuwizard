## The Prompt Engineering Framework

Writing prompts for AI image/video generation without trademarks requires a specific framework. The goal: evoke a familiar aesthetic using only generic visual grammar.

### The Framework: [GRAMMAR] + [CHARACTER] + [INVERSION] + [FORMAT]

1. **Grammar** — Describe the visual grammar of the format (lighting, camera, set, color)
2. **Character** — Describe the character using generic descriptors (no names, no brands)
3. **Inversion** — Describe the one element that's different (the joke)
4. **Format** — Describe the technical format (duration, resolution, aspect ratio)

### Example 1: Sitcom Bumper
```
[Grammar] A colorful multi-camera sitcom scene — warm wood-paneled living room set,
green couch, coffee table with vase of flowers, framed family photo on wall, warm
ambient studio lighting, medium shot slightly high angle, 1990s television aesthetic

[Character] SIX SHORT PEOPLE (vertically challenged adults, all around 4 to 4.5 feet
tall, dressed in normal 1990s clothing — jeans, sweaters, button-down shirts, blouses)

[Inversion] Every character is short — the visual hook is the contrast between the
normal sitcom scene and the fact that every single character is short

[Format] 10-second clip, 480p, whatever aspect ratio the scene demands
```

### Example 2: Game Show Bumper
```
[Grammar] Bright game show set, host podium, contestant podiums, audience cheering
in background, bright blue/red studio lighting, wide shot

[Character] Short game show host at podium, tall contestant at contestant podium,
short audience cheering

[Inversion] The height opposition — the contestant towers over the host, the audience
is all short, the height difference is treated as normal

[Format] 10-second clip, 480p, whatever aspect ratio the scene demands
```

### Example 3: Found Footage Bumper
```
[Grammar] Found footage, handheld camera, liminal hallway, fluorescent lighting,
cinderblock walls, industrial linoleum floor, VHS degradation, analog broadcast aesthetic

[Character] A Black man with an afro and a black hoodie with yellow WuBu lettering, carrying a staff with a
teal orb at the top, looking directly at the camera with a flat deadpan expression

[Inversion] The hallway is breathing — the walls expand and contract slightly, the
fluorescent light flickers in rhythm, the man doesn't react

[Format] 10-second clip, 480p, whatever aspect ratio the scene demands
```

## The Prompt Safety Checklist

Before submitting any prompt, check:
- [ ] No brand names (Friends, Price Is Right, Twilight Zone)
- [ ] No character names (Ross, Bob Barker, Rod Serling)
- [ ] No trademarked terms (Plinko, TARDIS, Dalek)
- [ ] No celebrity names (living or dead)
- [ ] No specific show titles
- [ ] Only generic visual grammar
- [ ] Only original character descriptions
- [ ] The three tests pass (Lawyer, Swap, Generic)

## Pitfalls
- **Too long** — Prompts over 500 words get truncated or ignored. Keep it under 300 words.
- **Too vague** — "A funny scene" is not a prompt. You need specific grammar, specific characters, specific inversion.
- **Forgetting the format** — Always specify duration, resolution, and aspect ratio. The AI needs to know what it's generating.

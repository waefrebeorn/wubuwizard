# Lilypad 18/25 — Scene Transitions: "But" and "Therefore" Between Scenes
# Domain: Scene Transitions | Chain: writing-room-25 | Depth: Leg 1
# 7-step Kevin Bacon: scene transitions → and then is death → but/therefore is life → scene-to-scene causality

## The Problem: "And Then" Between Scenes

Just as "and then" kills momentum within a sketch, it kills momentum between sketches. If bumper A ends and bumper B begins with no causal or disruptive connection, the audience feels the seam. They're watching a playlist, not a show.

Bad transition: "Old UNC stares at a vending machine. [cut] Old UNC is now in a game show. [cut] Old UNC is now in a hallway." → Three unrelated scenes. The audience is just waiting for the next thing.

Good transition: "Old UNC stares at a vending machine. The machine dispenses a game show buzzer. THEREFORE he's now on a game show. BUT the game show is in the same hallway. THEREFORE the hallway is now the game show set." → Each scene causes or disrupts the next.

## The Three Transition Types

### 1. "But" Transition (Disruption)
Scene A ends. Scene B disrupts it. The audience expects continuity; they get a break.

- The Old UNC is in a peaceful hallway. BUT the hallway is now a game show set.
- The game show is going normally. BUT the Old UNC's stare is making the host cry.
- The host is crying. BUT the audience (teal orbs) is loving it.

Each "but" is a left turn. The audience was going one direction; now they're going another. The surprise of the turn is the energy.

### 2. "Therefore" Transition (Consequence)
Scene A ends. Scene B is the result of Scene A. The audience sees the causality.

- The Old UNC presses a button on the vending machine. THEREFORE a game show buzzer comes out.
- He presses the buzzer. THEREFORE lights flash and a game show set materializes.
- The game show asks him a question. THEREFORE he stares at it until it apologizes.

Each "therefore" is a domino falling. The audience sees the chain and feels the momentum.

### 3. "Meanwhile" Transition (Parallel Cut)
Two scenes happening simultaneously, cut between. The comedy is in the contrast between the two scenes.

- Scene A: The Old UNC walks down a hallway, slowly.
- Scene B: A game show is happening at frantic speed.
- Cut between them. The contrast in energy is the joke.
- Eventually, the two scenes collide: the Old UNC walks through the game set. Both scenes become one.

## The South Park Rule Applied to Transitions

South Park's rule — "but or therefore between every beat" — applies to transitions between bumpers just as much as beats within a bumper. The entire ~ WuBu ~ channel should feel like one continuous "but/therefore" chain, even though it's made of 10-second pieces.

This means: when you're planning a sequence of bumpers, each bumper should cause or disrupt the next. The last beat of bumper 3 should connect to the first beat of bumper 4.

## Transition Devices

How do you actually connect two 10-second bumpers?

1. **Object carry:** An object from bumper 3 appears in bumper 4. The chicken from the vending machine is now on the game show podium.
2. **Character carry:** The Old UNC's action in bumper 3 causes his situation in bumper 4. He pressed a button → now he's on a game show.
3. **Visual match:** The last frame of bumper 3 visually resembles the first frame of bumper 4. A door closes → a different door opens.
4. **Audio carry:** The sound from bumper 3 continues into bumper 4. A buzzer sound from the game show continues over the hallway shot.
5. **Text carry:** A text card from bumper 3 is completed by bumper 4. Card in bumper 3: "The Old UNC's favorite thing about game shows is—" Card in bumper 4: "—the silence."

## The 10-Second Application

The transition IS part of the bumper. The last second of each bumper should set up the next:

- **Bumper 3, 0:09–0:10:** The Old UNC presses a button. A buzzer sounds.
- **Bumper 4, 0:00–0:01:** The buzzer sound continues. He's now on a game show.

The transition is seamless. The audience doesn't feel the cut.

## Pitfalls
- **Transitions that are too clever** — if the audience has to think "oh, that's a callback," the transition is too slow. It should be felt, not analyzed.
- **No transitions at all** — if every bumper is completely independent, the channel feels like a YouTube playlist. Connect them.
- **Forced causality** — if the connection between bumpers is illogical even by ~ WuBu ~ standards, it's not a transition, it's a non-sequitur.

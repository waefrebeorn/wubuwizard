# WUBUORIGINALS — FLAGSHIP SCRIPT SET (O-10 … O-15)

Six episodes, written 2026-09-29. Originals is the flagship channel under
Structure B, and these continue the O-3…O-9 run rather than restarting it.

## THE CHANNEL'S GRAMMAR, from the brief and the depot

- **Format:** found-footage. Shaky REC-cam, 4:3-ish letterbox inside 16:9, timecode
  running, diegetic text only, **no narration**.
- **The world:** storage units, the Order, the MEGA. The building is real and the
  paperwork is real and they do not agree.
- **UNC is never on camera in these.** O-6 and O-7 already established that
  Originals can be an empty corridor with no figure at all, and the DEP audit
  found the older Originals prompts leaning on negatives in the load-bearing
  position. These six are built so the **set is the character** — a load-bearing
  object that behaves like a person, which is the channel's actual idea.

**Every load-bearing detail in this file is a positive statement of a physical
object**, because `prompt_audit.py` enforces that and because I have now made the
negative-phrasing mistake five times.

## WHY THESE SIX

Originals' actual idea is that **the set behaves like a person and nobody says
so**. These are six variations on that, and they need no character at all:

- **O-10** a door handle shaped like a sleeping face that never wakes
- **O-11** a wall of numbers where every one is correct
- **O-12** an inventory that is always up to date, over an empty corridor
- **O-13** a sign with everything except the thing
- **O-14** one key, and the one door it is never put into
- **O-15** a tape that runs past the point of stopping

**Found-footage grammar:** one continuous handheld take per episode, no cuts,
timecode running, **no narration at all** — which is what separates this channel
from News, where the anchor's delivery is the joke.

**One corridor, one rig.** O-10, O-11, O-13 and O-14 are the same concrete
corridor with stencilled plates and can be shot back-to-back; O-12 and O-15 are
interiors and can be shot as a pair. Lowest drift cost of any batch so far.

**Run `setcheck.py` across the whole O group before hand-off**, with o6-t1 as
the reference set — six episodes in one corridor is exactly the condition that
produced the O-6 door-number drift.

## The Five Beats of a Sketch

Every comedy sketch — from a 30-second SNL bit to a 10-second bumper — follows the same five-beat structure. The only difference is the speed.

### Beat 1: Premise ("What if this situation?")
The premise is the setup. It establishes a world, a character, and a situation. The premise should be answerable as a "what if" question:

- "What if the Old UNC hosted a game show?"
- "What if a vending machine was alive?"
- "What if the hallway was watching him?"

The premise must be established fast. In a 10-second bumper, you have 2-3 seconds. A visual cue (game show set, vending machine, hallway) does this instantly.

### Beat 2: Game ("What's the funny thing?")
The game is the central joke of the sketch — the one funny thing that the whole scene is about. Every sketch has ONE game. Not two. Not three. One.

The game is the answer to: "What's funny about this situation?" 
- Game for "Old UNC hosts a game show": He treats the game show like a funeral.
- Game for "vending machine is alive": It has emotions about what it dispenses.
- Game for "hallway is watching him": It reacts to his mood.

The game must be clear by the 3-second mark. If the audience doesn't know what the funny thing is by then, they'll spend the rest of the bumper trying to figure it out instead of laughing.

### Beat 3: Heightening ("Escalate until it breaks")
Once the game is established, you escalate. Each iteration of the game is bigger, weirder, or more absurd than the last. The escalation follows the rule of three:

- **Iteration 1:** The game is introduced (Old UNC reads a question in a monotone)
- **Iteration 2:** The game is heightened (the question is "WHAT IS THE MEANING OF LIFE" and he reads it like a grocery list)
- **Iteration 3:** The game breaks (the question card is blank; he stares at it; the card stares back)

### Beat 4: Button ("The laugh at the end")
The button is the final beat — the biggest laugh, the one that ends the sketch. It's the culmination of the heightening. The button should be the funniest moment in the entire sketch, and it should come at the very end.

The button is often a:
- **Reversal:** the opposite of what the heightening was building toward
- **Topper:** one level beyond the last heightening
- **Silence:** the character just stares, and the stare is funnier than any line

### Beat 5: Tag ("Extra joke after the button")
The tag is a small joke after the button — a final punctuation. In a 10-second bumper, the tag is often the ~ WuBu ~ watermark appearing, or the Old UNC's final stare, or a quick visual gag in the last second.

## The 10-Second Sketch

All five beats in 10 seconds:
- **0:00–0:02** — Premise (visual: Old UNC is in a game show set)
- **0:02–0:04** — Game (he reads a question like a funeral director)
- **0:04–0:06** — Heightening (the question is increasingly absurd, his delivery stays the same)
- **0:06–0:09** — Button (the question card says "WHY?" — he shrugs — cut)
- **0:09–0:10** — Tag (~ WuBu ~ watermark, or a quick visual button)

## Why One Game?

If a sketch has two games, neither gets enough time to build. The audience is just getting into the first game when the second one starts. The result: two weak jokes instead of one strong one.

The discipline: pick ONE game and commit to it. If you think of a funnier game mid-sketch, save it for the next bumper. Don't try to cram both in.

## Pitfalls
- **Premise takes too long** — if you're still establishing at second 5, you've lost. Establish in 2 seconds or less.
- **Game isn't clear** — if you can't state the game in one sentence ("the Old UNC treats a game show like a funeral"), it's not clear enough.
- **Heightening goes sideways** — escalation must go UP, not sideways. A different joke at the same level isn't heightening.
- **Button is weak** — the button must be the funniest beat. If the heightening is funnier than the button, the sketch deflates at the end.

## Core Concept

Ryan Holiday's "Trust Me, I'm Lying: Confessions of a Media Manipulator" (2012) describes how stories propagate through the media ecosystem. The ~ WuBu ~ Television Universe is a media manipulation machine — it manufactures stories and trades them up the media stack.

## The Media Stack (Holiday's Model)

1. **Blogs** — Small, fast, no fact-checking
2. **Bigger blogs** — Pick up stories from small blogs
3. **Medium newspapers/broadcast** — Pick up stories from blogs
4. **Large newspapers/broadcast** — Pick up from medium outlets
5. **National news** — The story is now "real"

Holiday's insight: rumors travel online at speed/force and get "traded up" the media ecosystem until they become real headlines + real responses in real world.

## The WuBu Media Stack

~ WuBu ~ uses the same model for comedy:
1. **Bumper** — A 10-second clip (the "rumor")
2. **Channel** — The bumper airs on a ~ WuBu ~ channel (the "blog")
3. **Cross-channel** — The bumper references another channel (the "bigger blog")
4. **Rollout** — TikTok text clips, music clips, music-video clips (the "newspaper")
5. **Cultural conversation** — The audience shares, quotes, remembers (the "national news")

## The Culture Engine

Holiday's "culture engine" = manufacture stories, make them real. ~ WuBu ~'s culture engine:
1. Manufacture a bumper (the story)
2. Air it on a channel (the blog)
3. Reference it across channels (the bigger blog)
4. Roll it out as text clips (the newspaper)
5. The audience shares it (national news)

## Pitfalls
- **Too cynical** — Holiday's model is about manipulation. ~ WuBu ~ is about absurdity. The media stack is a tool, not a philosophy.
- **Forgetting the content** — The media stack only works if the content is worth sharing. The bumper must be funny first, viral second.
- **Too fast** — Holiday's model is about speed. ~ WuBu ~ is about precision. A 10-second bumper is not a rumor — it's a crafted artifact.

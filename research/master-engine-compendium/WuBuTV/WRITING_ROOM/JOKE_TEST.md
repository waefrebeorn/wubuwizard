# ✅ ~ WUBU ~ WRITING ROOM — JOKE TEST GATE
# The Minimal Scene Joke Test (chain-writing-room/23), distilled to a gate.
# RUN BEFORE GENERATING. Fail any question → fix the script, do NOT generate.
# Philosophy: test costs nothing; a generation slot + 3-5 min costs a slot.

---

## THE FIVE QUESTIONS
1. **Does a punchline exist?** Point to the EXACT frame/line that IS the laugh.
   ("The whole thing is funny" = no punchline = no joke.) → Fix: decide the ONE
   funny thing; make it the last beat.
2. **Does misdirection exist?** Does the setup create a SPECIFIC wrong
   expectation? If the audience sees the punchline coming, no surprise = no laugh.
   → Fix: make the setup straighter; guard down; punchline is the only laugh.
3. **Is it NOT obvious?** Show 100 people the setup — would >30% guess it? The
   first idea is usually the most obvious. Generate 5 punchlines; throw out the
   first two; the 4th/5th is usually the joke.
4. **Is it ACTUALLY funny?** Say the punchline out loud. Does it make YOU smile?
   Clever ≠ funny (a pun makes you groan; a joke makes you laugh). Add an
   emotional layer (what does it reveal about the character?).
5. **ONE thing happening?** Describe the joke in ONE sentence. Need more than one
   sentence → too busy. Cut to the funniest; save the rest for other bumpers.

## THE VERDICT
- PASS all 5 → eligible to generate (also clear the SCRIPT_TEMPLATE quality gate).
- FAIL any → revise. Most failures are: no punchline (Q1), or too obvious (Q3),
  or too busy (Q5).

## COMMON FAILURES (from the research)
- "It'll be funny when animated." No — if not funny on paper, render won't save it.
- Testing AFTER generating → you'll ship weak work because you spent the slot.
- Shipping a failed Q1 → that's a character existing, not a bumper.

## EXAMPLE (Scene: The Anti-Joke)
1. Punchline? YES — card "~ WuBu ~. We have no idea either."
2. Misdirection? YES — talk-show format promises an answer; gets silence.
3. Not obvious? YES — expected a deadpan one-liner; got nothing.
4. Funny? YES — host's desperation + button on the silence.
5. ONE thing? YES — "UNC sits in silence until host gives up."
→ PASS.

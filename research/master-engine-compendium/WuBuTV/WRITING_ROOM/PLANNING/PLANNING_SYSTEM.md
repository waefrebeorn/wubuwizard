## THE THREE SKILLS (what each is FOR)

### 1. SEVEN-STEP KEVIN BACON (Research Depth)
Don't stop at the first idea. Chain 7 deep: subject → adjacent → lineage →
counter-voice → technique → application → our universe. Each lilypad in
`chain-*/` was built this way (e.g. WuBu → bumpers → writing room → joke types
→ scene engines → misdirection → memetic television). Use it when you need to
DISCOVER what we know before writing.

### 2. 25-LILYPAD INDEXING (Knowledge Structure)
Take a domain, break it into 25 teachable pieces, layer them: Foundations →
Tools → Engines → Application → Testing → Index. This is how `chain-writing-room`
and `chain-television` are organized. Use it to ORGANIZE a research dump into a
curriculum the writer can navigate (see CRAFT_INDEX.md for the live map).

### 3. TRIPLE DEVIL'S ADVOCATE (Verification)
- DA-1 (Truth): verify on disk / by running, not by reading your own prose.
- DA-2 (Value): is this actually useful, or impressive-but-empty?
- DA-3 (Adversary): what breaks if we scale it / ship it / batch it?
Run DA on every plan and every finished script. The joke-test (JOKE_TEST.md)
is a DA-1/DA-3 gate specialized for comedy.

## THE PLANNING WORKFLOW (run this for every writing task)

```
PHASE 0 — BRIEF THE TASK
  What channel? What's the recurring bit this week? What's the GOAL
  (meme spread / establish voice / fill a gap / callback)?

PHASE 1 — KEVIN BACON (assemble the research)
  Pull the relevant lilypads from CRAFT_INDEX.md:
   - character anchor → CHARACTER_BIBLE.md
   - joke engine      → chain-writing-room/21 (toolkit)
   - tone/style       → chain-comedy-deep (deadpan, VHS, catchphrase)
   - satire register  → chain-crossover / chain-commentary / chain-meme
   - visual grammar   → chain-bootleg (legal-safe descriptors)
  Output: a "research dossier" (3-8 sources, cited by path).

PHASE 2 — INDEX THE ANGLES (25-lilypad thinking)
  For the task, list 5-9 distinct ANGLES (each a different joke engine /
  world-rule / format collision). Don't write one script — plan the SPACE
  of possible scripts. This is "better directions": the writer picks.

PHASE 3 — DRAFT THE PLAN
  For each angle: one-line premise + which engine + which recurring bit +
  the expected punchline TYPE. Use SCRIPT_TEMPLATE.md shape.

PHASE 4 — TRIPLE DA THE PLAN
  DA-1: does each angle have a real punchline? (run JOKE_TEST mentally)
  DA-2: are we repeating ourselves / is any angle empty?
  DA-3: would any angle trigger moderation (bootleg grammar scrub)? would
        batching 9 of them feel samey?

PHASE 5 — EMIT DIRECTIONS
  The plan becomes the writer's brief: pick an angle, fill SCRIPT_TEMPLATE,
  pass JOKE_TEST, generate. No blank page.
```

## HOW TO USE THIS INDEX (the writing workflow)
1. **Idea** → pick a channel brief (WuBuTV/WRITING_ROOM/CHANNEL_BRIEFS.md).
2. **Engine** → pick a joke engine (chain-writing-room/21 toolkit).
3. **Write** → use the SCRIPT_TEMPLATE.md (this dir).
4. **Gate** → run the JOKE_TEST.md (lilypad 23) — 5 questions, pass or fix.
5. **Prompt** → build the generation prompt from the CANONICAL character spec
   (CHARACTER_BIBLE.md) + bootleg grammar (chain-bootleg/) + corrected
   PROMPT_TEMPLATE.md.
6. **Generate** → only after the gate passes (fix-before-generate).

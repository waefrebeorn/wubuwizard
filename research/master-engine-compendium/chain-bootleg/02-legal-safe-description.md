## The Legal Framework

When generating images or video with AI, you need to avoid:
1. **Copyright infringement** — Using protected characters, settings, or designs
2. **Trademark infringement** — Using brand names, logos, or trade dress
3. **Right of publicity** — Using a person's likeness (celebrities, public figures)

The safe zone: describe *visual elements* that are generic enough to belong to no one but specific enough to evoke a recognizable aesthetic.

## The Three Tests

Before using any descriptor in a prompt, run it through three tests:

### Test 1: The Lawyer Test
"Would a lawyer recognize a specific IP in this description?"
- "A tall man in a black turban with a glowing blue staff" → SAFE (generic fantasy)
- "A tall man in a black turban with a glowing blue staff, the Dread Pirate Roberts" → UNSAFE (specific character)

### Test 2: The Swap Test
"Could I swap this descriptor with a different show/movie and still get the same result?"
- "Bright game show set, host podium, contestant podiums" → SAFE (works for ANY game show)
- "The Price Is Right set with Plinko board" → UNSAFE (specific to one show)

### Test 3: The Generic Test
"Is this descriptor a category or a specific instance?"
- "Multi-camera sitcom" → SAFE (category)
- "The Friends opening sequence" → UNSAFE (specific instance)

## Safe Descriptors by Category

### Sitcom Grammar
- Multi-camera setup, warm lighting, wood-paneled set, couch, coffee table, laugh track, studio audience, 1990s aesthetic
- Three-wall set, kitchen island, dining table, family photos on wall, warm color palette

### Game Show Grammar
- Bright studio lighting, host podium, contestant podiums, audience seating, colorful backdrop, buzzer system, scoreboard
- Split-screen format, before/after comparison, enthusiastic host, prize display

### Talk Show Grammar
- Desk, guest chair, monitor, studio lighting, band, audience seating, interview format
- Two chairs, spotlight, intimate lighting, conversational format

### News Grammar
- News desk, anchor, monitors, studio lighting, breaking news graphic, lower-third text
- Field reporting, handheld camera, location backdrop, serious tone

### Horror Grammar
- Found footage, handheld camera, liminal space, fluorescent lighting, VHS degradation, institutional setting
- Dark hallway, flickering light, uncanny stillness, analog broadcast aesthetic

## Pitfalls
- **Over-caution** — "A person in a room" is safe but useless. You need SPECIFIC grammar, not NO grammar.
- **Inconsistency** — If you establish "warm sitcom lighting" in frame 1, don't switch to "horror lighting" in frame 2 unless the joke requires it.
- **Forgetting the format** — Each format has its own grammar. Don't mix sitcom lighting with horror camera work unless you're deliberately creating a format collision (which IS the ~ WuBu ~ style).

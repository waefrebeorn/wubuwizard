# Lilypad 19/25 — Multiple Threads: Everything on Screen at Once
# Domain: Multi-Thread Comedy | Chain: writing-room-25 | Depth: Leg 1
# 7-step Kevin Bacon: multiple threads → balls in a tank → SA-TV → satire-as-action → everything collides

## The Single-Thread Problem

Most comedy has one joke at a time. Setup → punchline → next joke. The audience follows a single thread from beginning to end. This works, but it's not dense.

The alternative: multiple joke threads running simultaneously. The audience's attention splits between them, and the comedy comes from the collision.

## SA-TV: Satire-as-Action

The ~ WuBu ~ format is SA-TV — satire-as-action. Everything is on screen at once. The Old UNC is doing something in the foreground. The background has a visual gag. A text card is delivering a one-liner. The environment is doing something weird. All at the same time.

This is the "balls in a tank" principle applied to a single frame. Not just multiple jokes in a scene — multiple jokes in a single moment.

## How to Run Multiple Threads

### Thread 1: The Main Action (foreground)
What the Old UNC is doing. This is the primary joke — the one the audience follows if they're only paying partial attention.

### Thread 2: The Background Gag (background)
Something happening behind the Old UNC that contradicts or comments on the main action. He's having a serious moment; behind him, a chicken is walking in circles.

### Thread 3: The Text Layer (lower-third or title card)
A text joke that runs parallel to the visual. The Old UNC is staring at a door. The text says something unrelated that creates a third joke when combined with the visual.

### Thread 4: The Environmental Thread (the world)
The environment itself is doing something. The hallway is breathing. The lights are flickering in a pattern. The vending machine is humming a melody.

## The Collision

The comedy peaks when two or more threads collide. The Old UNC's action causes a reaction in the background. The text card recontextualizes the visual. The environment responds to the character.

Example:
- **Thread 1:** Old UNC walks down a hallway (main action)
- **Thread 2:** A chicken follows him two steps behind (background gag)
- **Thread 3:** Text card: "Day 47 of the chicken situation" (text joke)
- **Thread 4:** The hallway is slightly tilted (environmental weirdness)

**Collision:** The Old UNC stops. The chicken stops. The text changes to "It won't leave." The hallway tilts further. All four threads converge on the same joke.

## Equal Opportunity Offense (Thread Edition)

Multiple threads let you make fun of everything at once. The main action can be about one thing, the background gag about another, the text about a third. In 10 seconds, you can hit three different targets. This is South Park's "equal opportunity offense" in structural form.

## The 10-Second Application

Every bumper should have at least two threads running:
- **Primary thread:** The main joke (the Old UNC doing something)
- **Secondary thread:** A background detail, text card, or environmental element that adds a second joke

The audience that only catches the primary thread still gets a joke. The audience that catches both gets a richer experience. This is how you reward repeat viewing.

## Pitfalls
- **Too many threads** — if there are five things happening at once, the audience can't track any of them. Two threads is the sweet spot. Three is the max.
- **Threads that don't collide** — if the background gag has nothing to do with the main action, it's just noise. The threads need to connect.
- **Secondary thread is funnier than the primary** — if the background gag is the best joke in the bumper, it should be the primary thread. The main action must be the strongest joke.

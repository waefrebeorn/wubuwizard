## The Cross-Reference Map

### If you're building a joke from scratch:
Start with **07** (Humor Blueprint: 4-step engineering) → pick a joke type from **16** → structure it with **01** (Setup → Punchline) → test it with **23**.

### If you're writing a bumper script:
Pick a format from **20** (Comedy Remix) → pick an engine from **21** (Scene Engines) → structure it with **14** (Sketch Structure) → add density with **19** (Multiple Threads) → test with **23**.

### If your joke isn't landing:
Check **10** (Misdirection — is there a wrong expectation?) → check **04** (Humor Theories — which theory are you using?) → check **23** (Joke Test — which question are you failing?).

### If your bumper feels empty:
Add a second thread from **19** (Multiple Threads) → add a callback from **11** → add a tag from **09** (Joke Stacking) → add a sight gag from **08**.

### If your bumper feels too busy:
Check **23** Question 5 (ONE thing happening?) → cut to the core game from **14** → simplify to one joke type from **16**.

### If you're building a series of bumpers:
Use **17** (Comedy Platforms) to create a world → connect them with **18** (Scene Transitions) → build callbacks with **11** → remix formats with **20**.

## The Research Architecture

The 25 lilypads form a complete curriculum:

```
FOUNDATIONS (how jokes work)
    ↓

    ↓
ENGINES (how to generate comedy)
    ↓
APPLICATION (how to build bumpers)
    ↓
```

Each layer depends on the layer below it. You can't build a bumper (Layer 4) without an engine (Layer 3). You can't use an engine without tools (Layer 2). You can't use tools without understanding foundations (Layer 1).

## The Writing Room Mantra

The five principles that govern everything:

1. **Setup is straight. Punchline does the work.**
2. **But/therefore between every beat.**
3. **One game per bumper.**
4. **Punch word at the end.**
5. **Test before you generate.**

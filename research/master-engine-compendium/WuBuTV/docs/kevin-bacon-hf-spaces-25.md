## NODE 1: MiniMax-H3 → The Audio-to-Video Breakthrough
**Chain**: MiniMax-H3 → joint video+audio generation → 9:16 vertical → free → programmatic
- MiniMax-H3 is an Omni-Transformer that jointly predicts video and audio latents
- Unlike FLUX 3 (dead), it accepts AUDIO as input, not just text/image
- Generates stereo audio synchronized to video — no separate audio pipeline needed
- 9:16 vertical format native (768x1344) — perfect for TikTok/Reels
- Free, no login, accessible via gradio_client Python API
- **WuBu application**: Generate bumpers where the audio IS the joke (meme sounds + absurd visuals)

## NODE 2: Wan2.2 → The Image-to-Video Workhorse
**Chain**: Wan2.2 → 14B params → consumer GPU friendly → 14+ spaces → fast
- Wan2.2 uses Mixture-of-Experts (MoE) architecture for efficient inference
- TI2V-5B variant runs on single RTX 4090 (24GB)
- Apache 2.0 license — fully commercial
- 14+ working spaces on HuggingFace (more than any other model)
- **WuBu application**: Generate first frame with FAL → animate with Wan2.2

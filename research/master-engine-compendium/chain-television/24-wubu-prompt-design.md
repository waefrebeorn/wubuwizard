## The WuBuMovie's Grok Imagine Prompt Design

The WuBuMovie's prompts for Grok Imagine (the bumper generator) should be designed with the research from all 24 previous lilypads. The prompts should not generate "environments" — they should generate "characters in a world with rules." The prompts should be designed for "memetic spread" — the outputs should be shareable, visual, simple, repeatable.

## The Prompt Template

The WuBuMovie's prompt template (based on all 24 lilypads):

```
[original visual anchor] + [character with specific personality] + [world with specific rules] + [action/event that reveals character] + [memetic visual motif] + [tone: horror + comedy] + [format: 10-second bumper, 480p, whatever aspect]
```

## The Prompt Design Principles

1. **Character first, environment second.** The Old UNC (the character) is the prompt's focus — the storage unit (the environment) is the setting. The prompt should generate the character's personality, the voice, the stare, the behavior. The environment is the context.
2. **World rules in the prompt.** The storage unit's rules (the cinderblock walls, the industrial linoleum, the fluorescent light, the giant white plate) are the world rules. The prompt should generate the world's rules — the audience should feel the world's logic.
3. **Memetic visual motif.** The giant white plate is the WuBu signature element — the prompt should generate the plate (the visual motif that the audience remembers). The teal-orb staff is the Old UNC's identity — the prompt should generate the staff (the visual motif that the audience remembers).
4. **Tone: horror + comedy.** The prompt should generate the horror (the uncanny, the unsettling, the liminal) AND the comedy (the deadpan, the absurdity, the weirdness). The horror and comedy should be in balance — not horror with a joke, but horror AND comedy as equal elements.
5. **Format: 10-second bumper, 480p, whatever aspect.** The prompt should generate a bumper (a 10-second clip), not a scene (a 2-minute clip). The bumper is the WuBuMovie's "unit of distribution" — the audience experiences the bumper, shares the bumper, remembers the bumper.
6. **The tail-end footer.** The footer ("strict reference adherence needed...") is the WuBuMovie's "meta instruction" — it tells the AI that the bumper is part of a larger universe, that the bumper is mixed media, that the bumper can be cut. The footer is the WuBuMovie's "world rules" in the prompt.

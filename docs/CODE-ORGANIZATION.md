# Code Organization — one engine, one owner, one gate

## Directory contract

| Path | Owns | Rule |
|------|------|------|
| `include/wubu_*.h` | Public seams | Opaque structs at module boundaries; minimal includes |
| `src/wubu_*.c` | C11 implementation | No stubs, no vendored libraries, no platform intrinsics in model code |
| `src/quantized_*.c`, `src/dequant_*.c` | Quant decode | One format per function family; differential test against reference |
| `src/gpu_*.cu` | CUDA backend | Dispatch only; mirrors a CPU kernel, never replaces it |
| `tools/test_*.c` | Gates | Named `make test_*`; assertions cover the mechanism, not the vibe |
| `tools/*.c` | Binaries/CLIs | Thin wrappers; no logic that belongs in `src/` |
| `tests/fixtures/` | Tiny GGUF fixtures | Generated by `tools/make_*_fixture.py`, committed |
| `docs/` | Architecture and plans | Durable knowledge; no transient status |
| `.hermes/` | Per-project palace | Goal, state, vault, walkway; gitignored except explicit artifacts |

## Module seams

```
agent / goal (host, LP-01..04)
        |
   wubu_goal_t  →  wubuwizard engine  ←  Wua scripting
        |              | | | |
        |        quant  KV  loop  sampling
        |              | | | |
        +--- backend dispatch (CPU / CUDA / HIP)
                       |
              WuBuHIVE + WuBuKernel
```

The engine never imports goal/state logic. Host modules never reach into kernel internals.

## Naming

- Public type: `wubu_<module>_t`; construct/destroy `wubu_<module>_init` / `_free`.
- Gate binary: `tools/test_<module>.c`, target `test_<module>` in both Makefiles.
- Backend entry: `wubu_<op>_cpu`, `wubu_<op>_cuda`, `wubu_<op>_hip`.
- Family rows: compiled specialization, identical kernel bodies.

## Ownership map

| Concern | Owner module | Gate |
|---------|--------------|------|
| Model load + GGUF metadata | `gguf_reader` | `test_arch_probe` |
| Quant decode | `dequant_*`, `simd_quant` | `test_simd_quant`, `test_nvfp4_weights` |
| KV spine | `kv_exact`, `kv_fetch`, `swa_reclaim` | `test_kv_*` |
| Loop executor | planned `loop` | `test_loop_depth` |
| Speculation | `spec_budget`, `spec_seed`, `spec_constrained` | `test_spec_*` |
| Goal/judge | `wubu_goal`, `goal_steer`, `goal_resample` | `test_goal*` |
| State/ABI | `state_version` | `test_state_version` |
| Backends | `gpu_*` | `test_backend_*` |

## Rules

1. **One owner per concern.** If two modules own the same state, the design is wrong.
2. **One gate per module.** No gate, no ship. A doc edit is not a gate.
3. **CPU is the reference.** Every accelerated kernel is differentially tested against it.
4. **No vendor leakage.** CUDA/HIP intrinsics stay in backend translation units.
5. **No forks for hardware.** Tiers are runtime config and compile rows (see `TIERS.md`).
6. **Absorb, don't duplicate.** When a technique is learned from another engine, it lands
   in an existing module with a gate — not a parallel copy.

## Historical consolidation

- bytropix (retired): IQ2_XS dequant lineage and C style; palace artifacts absorbed into
  `.hermes/`. No branch, no fork.
- slermes: goal/judge logic lives in the host module, not the engine.
- big-mac: SIMD/DSP discipline as reference only.
- llama.cpp / ggml: format and reference outputs only; nothing vendored.

# Lilypad 16/25 — Punchline Types: The Full Taxonomy and When Each Works
# Domain: Punchline Taxonomy | Chain: writing-room-25 | Depth: Leg 1
# 7-step Kevin Bacon: punchline types → misdirection → analogy → exaggeration → absurdity → wordplay → observation → act-out → POV

## Why Taxonomy Matters

Not all punchlines work the same way. Different punchline types create different kinds of laughs — quick laughs, slow laughs, big laughs, subtle laughs. The writing room needs all of them, and needs to know which to use when.

## The Eight Punchline Types

### 1. Misdirection Punchline
The audience expects A; they get B. The punchline recontextualizes the setup.
- **Laugh type:** Quick, sharp. The "oh!" laugh.
- **Best for:** One-liners, quick gags, bumper buttons.
- **Example:** Old UNC opens a door. Behind the door: another door. He nods, satisfied.

### 2. Analogy Punchline
Two unlike things are compared, and the comparison reveals something true.
- **Laugh type:** Slow build. The "hmm... oh!" laugh.
- **Best for:** Observational comedy, character-driven bits.
- **Example:** "The hallway is like a waiting room for a doctor who doesn't exist."

### 3. Exaggeration Punchline
A normal situation is pushed to an impossible extreme.
- **Laugh type:** Big, physical. The "that's too much!" laugh.
- **Best for:** Physical comedy, visual gags, escalation.
- **Example:** Old UNC waits for an elevator. The wait time display shows "∞".

### 4. Absurd Punchline
The punchline doesn't make logical sense but makes emotional sense.
- **Laugh type:** Confused-then-amused. The "wait, what... okay that's funny" laugh.
- **Best for:** Absurdist comedy, dream sequences, non-sequitur tags.
- **Example:** Old UNC presses a button. A voice says, "That button hasn't worked since the 70s." He says, "I know," and walks away.

### 5. Wordplay Punchline
The humor is in the language itself — double meanings, puns, unexpected word choices.
- **Laugh type:** Groan or chuckle. The "that's clever" laugh.
- **Best for:** Text cards, lower-third gags, quick hits.
- **Example:** Text card: "The Old UNC's favorite game show: WHO WANTS TO BE A MILLIONAIRE'S LAWYER."

### 6. Observation Punchline
The comedian points out something the audience already knew but never articulated.
- **Laugh type:** Recognition. The "that's so true!" laugh.
- **Best for:** Character comedy, world-building, relatable humor.
- **Example:** "You ever notice vending machines only eat your money when you're hungry? When you're not hungry, they work fine."

### 7. Act-Out Punchline
The comedian physically demonstrates something, and the demonstration is the joke.
- **Laugh type:** Physical. The "I can see it" laugh.
- **Best for:** Visual comedy, physical gags, character bits.
- **Example:** Old UNC tries to walk through a doorway that's slightly too small. He turns sideways. Still too small. He walks away without a word.

### 8. Point-of-View Punchline
The joke is in how the character sees the world, not in what happens.
- **Laugh type:** Slow, character-based. The "that's just how they are" laugh.
- **Best for:** Recurring characters, running gags, world-building.
- **Example:** Old UNC looks at a chaotic game show set and says, deadpan, "This is fine."

## Matching Punchline Type to Bumper Type

| Bumper Format | Best Punchline Types |
|---|---|
| Found footage | Misdirection, Absurd, Act-Out |
| Game show | Exaggeration, Contrast, POV |
| Sitcom | Observation, Callback, Act-Out |
| Talk show | Analogy, Wordplay, Observation |
| Horror | Misdirection, Absurd, POV |
| Commercial | Exaggeration, Wordplay, Analogy |

## Mixing Types

The best bumpers mix two punchline types: one for the main joke, one for the tag. A misdirection punchline into an act-out tag. An observation punchline into an absurd tag. The mix keeps the audience from predicting the pattern.

## Pitfalls
- **Using the same type every time** — if every bumper is misdirection, the audience catches on. Rotate types.
- **Wordplay in visual formats** — if the bumper is purely visual (found footage), wordplay won't work. Match the type to the medium.
- **Observation without insight** — "elevators are slow" isn't an observation, it's a fact. An observation needs a fresh angle.

# Lilypad 9/25 — Joke Stacking: Tags, Runs, Escalations, and Callbacks
# Domain: Joke Architecture | Chain: writing-room-25 | Depth: Leg 1
# 7-step Kevin Bacon: joke stacking → premise → setup → punchline → tags → runs → escalations → callbacks

## One Joke Is Never Enough

A single punchline is a sketch. A stack of punchlines is a *bit*. The difference is density — how many laughs you pack into the same premise. Joke stacking is the art of getting multiple laughs from a single setup.

### The Architecture of a Bit

1. **Premise** — the situation (one time only)
2. **Setup** — the initial context (one time only)
3. **Punchline** — the first laugh (the biggest)
4. **Tag** — an additional punchline on the same premise (smaller laugh, faster)
5. **Tag** — another one (even smaller, even faster)
6. **Run** — a series of tags that escalate back up
7. **Callback** — a reference to an earlier joke (recognition laugh)

## Tags: Riding the Laugh

A tag is a second punchline delivered while the audience is still laughing at the first. It doesn't need a new setup — it rides the momentum of the first joke.

Example:
- Punchline: "The Old UNC opened the door. The door opened to nowhere."
- Tag 1: "He closed it. Opened it again. Still nowhere."
- Tag 2: "He checked the back of the door. That was nowhere too."

Each tag is shorter than the last. The audience's laugh doesn't fully die between tags — it ripples. Three tags in quick succession feels like one big laugh, but it's actually three laughs stacked.

## Runs: The Series

A run is a string of tags that follow a pattern. The audience catches on to the pattern and starts laughing *before* each tag lands, because they know what's coming and want to see how you do it this time.

Example (the vending machine run):
- "The Old UNC pressed A1. A live chicken came out."
- "He pressed B2. A smaller chicken came out."
- "He pressed C3. A chicken that was also a clock came out."
- "He pressed D4. The machine just sighed."

The run establishes a pattern (press button → get chicken variant), escalates it (the variants get weirder), then breaks it (the machine sighs — personification subversion). The audience laughs at each step because they're ahead of the joke, and then the last one pulls the rug out.

## Escalation: Each One Bigger

Every tag in a stack should be bigger (or weirder, or more absurd) than the last. If a tag is smaller than the previous one, the bit deflates. The audience feels the energy dropping and stops laughing.

The escalation can be:
- **Scale:** the objects get bigger, the spaces get wider
- **Absurdity:** each tag is less logical than the last
- **Stakes:** each tag raises the implied stakes (even in a meaningless context)
- **Speed:** each tag comes faster, compressing the timing

## Callbacks: The Recognition Laugh

A callback is a reference to a joke you told earlier — either earlier in the same bit, or in a previous bumper. The laugh comes from recognition: "Oh! That thing from before! It's back!"

Callbacks are the most efficient joke type because they do double duty — they're a new joke AND a reward for paying attention. The audience feels smart for getting it.

**In a 10-second bumper:** A callback can be visual (the chicken from the vending machine appears in the background of a later bumper) or textual (a lower-third card references an earlier card). The callback doesn't need to be the main joke — it can be a background detail that rewards repeat viewers.

## The 10-Second Stacking Formula

In 10 seconds, you can fit:
- **0:00–0:03** — Setup (establish the premise)
- **0:03–0:05** — Punchline (first laugh)
- **0:05–0:07** — Tag 1 (second laugh, riding the first)
- **0:07–0:09** — Tag 2 (third laugh, escalating)
- **0:09–0:10** — Button (final punctuation — a stare, a cut, a ~ WuBu ~ watermark)

That's 3-4 laughs in 10 seconds. That's density.

## Session Context: What the Television Research Found About Stacking

- **The Crypt Keeper's puns as tags** (Lilypad 11, chain-television): The Crypt Keeper delivered a pun at the START and END of each episode. The second pun was the "tag" — it rode the momentum of the first. In ~ WuBu ~ bumpers, the Old UNC's stare at the end is the tag — it rides the momentum of the punchline.

- **Matheson's "The New Exhibit"** (Lilypad 04, chain-television): A museum of wax figures that come to life. Each figure is a new "tag" — a fresh absurdity that escalates from the last. The vending machine chicken is the same: each bumper is a new "figure" that escalates.

- **Memetic television's "twist + callback"** (Lilypad 19, chain-television): The most memetic shows (Doctor Who, The Simpsons) use callbacks as tags. "Don't blink" is a callback that's also a tag — it references an earlier episode while being a new joke. The ~ WuBu ~ callbacks (the chicken, the hallway, the teal orb) work the same way.

- **Game show "heightening"** (Lilypad 15, chain-television): In Family Feud, each round is bigger than the last. The stakes escalate. In ~ WuBu ~ bumpers, each tag escalates the absurdity — the chicken becomes two chickens, then a chicken that's also a clock.

## Pitfalls
- **Tags that aren't jokes** — a tag must be a real punchline, not just a restatement. "The chicken came out. Then another chicken came out" is not a tag. "Then another chicken came out, wearing the first chicken's clothes" is a tag.
- **Too many tags** — if the audience stops laughing and you're still tagging, you're killing the bit. Stop while they still want more.
- **Callbacks that need explanation** — if you have to explain the callback, it's not a callback. It's a new joke with homework.
